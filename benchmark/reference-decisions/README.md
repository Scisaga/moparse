# 独立人工参考裁定

这里保全既有人工排除决定和该记录指定的原页截图，不保存管线成绩或旧输出比较。它与Lite/Full冻结包分开；本次仅搬迁既有材料，没有重新阅读原页、改写参考、接受其他内容或形成新裁定。

reference-adjudications.json的决策身份、动作、适用范围、审核者、来源判断及理由保持原内容。仅把evidence定位到本目录的两张原页图片，并移除混有旧候选比较的报告引用；因此这是存放元数据迁移，不宣称整个JSON字节未变。

evidence_base=run_directory延续原记录的相对证据根约定。后续run使用这一决定时须同时搬运记录列出的图片，保持相对位置；只复制JSON不能证明图片已经进入新run。现有exclude_unit_pending保持待判排除，不修改冻结答案，不按配置或轮次选择有利输出。

本目录全部材料永久排除通用内容、格式、链接和映射检查，包括显式路径调用；自动评分许可不等于机械复核或重新验收参考。
