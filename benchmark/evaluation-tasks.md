# MO-Parse 解析评测任务与数据集

本文件定义下一轮解析管线基准的任务、外部输入交接要求、评分和计时规则。解析预期结果与语料的生成已在其他项目开展，本仓库不再维护原本地样本目录或重复生成语料与金标。具体输入与标注版本待交接确认；这里不继承历史成绩，也不把外部生成工作已开展视为本轮基准已完成。

评价对象是管线的原始解析结果和忠实 Markdown 导出，不是 MO-Parse 接口最终格式。候选结果可以保留表格、源图、页码及页眉页脚；数据表语义转换和页面清理由服务另行实现、测试和计时，图片语义化不在当前范围。研究问题与步骤见[研究框架](../docs/research/research-framework.md)，工程交接见[技术路线](../docs/engineering/technical-route.md)。

额外引入的六份公开原件已集中保存在 [`pdf_sample_extra/`](../pdf_sample_extra/README.md)，共 46 页，**暂不处理**。这些文件不进入本轮解析、评测、调优、预热、回归验收或上线判断；历史固定 Office 转换 PDF 也不纳入本轮输入。

## 评测任务

| 任务 | 输入特征与代表材料 | 需要准备的原件标注 |
| --- | --- | --- |
| 原生 PDF 正文 | 有原生文字、段落和标题的完整 PDF | 正文转录、段落边界、标题层级、阅读顺序及原件空白 |
| 扫描 PDF 文字 | 扫描页和旋转文字或表格 | 完整选定区域转录、文字块、原始及正确阅读方向、数字与符号 |
| 混合 PDF 页面 | 文字层和扫描图像共存的页面 | 区域来源类型、覆盖关系、逐区转录与跨区顺序 |
| 表格内容与结构 | 字段、记录、比较矩阵、混合表与复杂跨度 | 完整表的文字、空位置、行列格位与跨度、表头路径、单位期间和附注原文及范围 |
| 跨页内容与表格关系 | 正常续表及邻接不同期间表 | 片段边界、完整来源表头、续表关系、新表分界、单位期间变化和内容保全 |
| 图形及媒体保全 | 以外部交接清单确认流程图、组织图及其他嵌图的覆盖 | 原件区域、图像、caption、可见文字和原始位置；不设置图片节点、连线或层级标注与评分 |
| 页面内容区分 | 正文与页码页眉页脚、页边附注和签章日期 | 区分业务正文与页面家具以便独立统计；不要求候选执行 MO-Parse 的清理功能 |

来源页码均指 PDF 物理页码。任务有交集，不能相加成输入数；来源类别由原件文字层、图像覆盖和独立复核确定，不能用解析器选了什么路径反推真值。图形只有源图或 OCR 时分别记录本方法实际能力，不称为恢复了连线关系，也不要求其生成服务用多层列表。

数据表语义描述、网格排版还原、图片交付、页面家具清理及接口正文一致性属于[MO-Parse 服务契约](../docs/specs/moparse-output-spec.md)的功能测试，不在本轮解析评分中设为共同输出要求或准入条件。

## 外部语料与预期结果交接

完整 PDF、解析预期结果与独立标注由其他项目生成和维护。本项目接收明确纳入本轮的冻结版本，不恢复已删除的本地样本，也不从旧实验输出、旧裁图或旧页面组合重建语料。

交接清单应包含原件身份、来源与许可、SHA256、物理页数、来源类别、文档家族、开发使用情况、标注版本及覆盖范围。运行前核对同一批完整原件与标注的对应关系，具体文档数、页数和已标注分母以交接清单为准；当前不声明替代语料已经交付。

额外六份公开原件继续按[暂不处理清单](../pdf_sample_extra/README.md)保留，不自动作为替代输入。其他项目开展生成不等于本项目获准执行解析、评测或调优。

## 外部标注要求与测试集划分

接收外部标注时核对来源类型、语言、方向、版式、文档家族及完整评价单位和分母。先区分数据表、网格排版和混合区域，网格排版检查正文及顺序，不能要求强转表格关系。正文覆盖完整段落或全文；数据表覆盖完整物理表的文字、空格位、跨度、表头及单位期间原文；跨页关系同时覆盖应连接与应分开的片段；图形保留原图、可见内容和评价范围。不能只挑模型容易答对的数字或短锚点。

外部标注应在查看待测输出之前冻结，每项记录原件身份、物理页、区域、预期内容、可辨状态和复核人，歧义项独立复核。旧线索须回看原件并冻结新版本后才进入分母。未标注、不可辨、方法未提供、未识别和失败分别记录；尚未完成的任务不填正确率或零错误。

表头、期间、单位和跨页范围的原件标注用于核对解析是否保真，不要求候选先转为完整语义关系模型。某方法原生提供节点连线、字段关联等额外结构时，独立标注后可以单列能力与正确性；不能把未提供结构写成正确或要求其他方法先开发同等服务功能。

评分读取只读原方法已有信息；先排除原始响应到读取/导出的丢失，不能在读取时用金标或另一方法补齐。MO-Parse 的关系转换和渲染可以使用正确结构做单独功能测试，但这不是解析比较的前置步骤，也不能将其结果算成候选解析能力。

外部交接需说明原件是否用于开发；其他页面、裁图、旋转件和同模板文档不能冒充独立未见样本。按完整文档或家族分组，分别报告每个任务已标注的文档、页、段落、表和关系数。处理页数不等于标注覆盖页数；独立泛化能力只依据已明确纳入范围的未见原件评价。

## 评分定义

各组先按[原生输出说明](../docs/pipelines/README.md)确认评分读取实际面对的结构、媒体及状态。原生已有信息在读取时丢失，应修复读取；入口没有传出的信息、方法没有产生的信息和服务适配未完成分开记录。格式说明和适配组件测试不提供解析质量分数，也不要求八组先输出共同语义结构。

| 指标 | 比较对象与分母 | 评价含义 |
| --- | --- | --- |
| 正文字符错误率 | 已标注业务正文的来源字符 | 按替换、删除、插入的编辑距离计算，遗漏和新增另留诊断 |
| 正文完整性与顺序 | 已标注段落、文字块与顺序关系 | 检查整段保全、遗漏、重复及阅读顺序 |
| 表格文字与网格 | 完整标注表的单元格文字、空位、格位和跨度 | 文字与结构分报；未提供结构另报能力及覆盖，不能填零错误 |
| 表头与限定信息 | 已标注表头路径、合并范围、单位、期间及附注原文 | 核对原文、作用列/行与来源归属，不要求改写成自然语言 |
| 数值与归属 | 已标注数值所在原件行列、符号、单位和期间 | 数字、正负号、小数、百分号及原件位置分别核对，不能以数字出现代替归属正确 |
| 跨页表格关系 | 已标注续表边、新表分界和完整来源内容 | 分报正确、错误和漏连接，保全全部表头、单位期间及单元格；未合并但物理表完整与错误合并分开 |
| 图形内容保全 | 已清点且标注的图像区域、caption 和可见内容 | 核对图像和文字是否遗漏、错位或损坏；源图保全与 OCR 文字分别报告，不评价图片语义关系 |
| 原生结构能力 | 按独立标注评价方法实际提供的字段、节点、边或层级 | 报告可用范围、精确率和目标召回，不强制统一内部表示或服务语义列表 |
| 来源与失败保全 | 所有输入页及预先标注异常区域 | 检查页覆盖、必要资产、未知和失败是否被完整记录 |

保留 GFM/HTML 表格、页码页眉页脚或原图不是服务最终格式失败；主比较不评分“无表格”“多层语义列表”或“页眉页脚已删除”。业务正文与家具分开统计，家具不进入业务正文 CER，页边业务附注、签章和日期仍在应保留分母；混入正文顺序或遮蔽内容造成的真实错误仍要记录。

评价按原件信息定义，不要求某框架私有字段或矢量网格。Markdown 无法表达的已有跨度等信息从原生结果读取；原方法缺失与读取代码丢失分开归因。不能凭相同字形、相似首行或列数相等证明表头含义和跨页关系，更不能以 MO-Parse 转换失败代替原始解析判断。

关系精确率以本方法输出的确定关系为分母，召回以全部已标注目标关系为分母；未知和未输出仍在目标覆盖中单列。来源不可辨和未标注不填正确，也不冒充有确定金标。方法未提供某项结构时，报告能力缺口与目标覆盖，同时保留其文字和图像的独立结果，不能仅统计已恢复片段。

每项指标在运行前固定评分方式、分母、缺失及未知规则，按文档和类别报告覆盖。局部检查写明“通过数/检查数”，不同单位和重叠套件不累计成总准确率。少量检查零错误不代表全量正确，没有实际来源或未标注的图形类别写未覆盖；服务输出格式与下游抽取收益另行评价。

文字内容比较使用新基准政策`mo-parse-eval-text-v1`：只将U+FF01至U+FF5E映射为对应ASCII字符，将U+3000映射为空格，并列保留严格字符诊断。是否折叠空白由各任务预先固定；不使用NFKC、不删标点、不修数字。宽度等价不能补出缺失文字、单位、期间、表头或跨度，也不能证明两张表应合并。

## 从评价到采用的规则

正式执行前按任务约定关键错误、最低覆盖、可接受质量及资源上限，说明比较优先级；目前数值门槛尚待准备，不以已有表格语义实现通过数或本轮最好成绩倒推。门槛用于判断能否采用，全部八组仍保留在完整对照中。

同一原件、段落、表和来源关系配对比较，分别报告每份文档与每类任务，汇总时明确按文档还是按内容数量计权。长表的简单数字不能掩盖其他文档的关键错值、错表头或遗漏，不将不同指标随意相加为总准确率。三次测量不是三个独立 PDF 样本。

先核对关键质量、覆盖和资源，再比较处理成本；质量与成本各有长短时保留取舍，未预先约定权重就不生成单一总分。某类别没有来源、标注或充分支持时，不能用它做选型或路由依据。具体决策顺序见[研究框架](../docs/research/research-framework.md#7-固定方法与条件性路由)。

## 统一执行与计时边界

所有管线接收同字节完整 PDF，使用同一输入顺序、共同前处理、独立标注、忠实导出规则、评分和资源预算。配置按[待测试管线](pipelines-to-test.md)固定；先确认原始结果可保存、已有信息能正确读回，再比较实际解析质量。无需先冻结 MO-Parse 语义转换器或通过服务格式检查，正式结果保留全部八组的失败、未知与超预算。

主耗时在 worker 内以单调时钟直接测量：完整 PDF 已就绪且 worker 取得执行权后开始处理，至原始解析、研究侧忠实 Markdown 和必要资产生成完成。包含必要原件读取、方向与分类、路由、PDF 渲染、全部声明解析推理、必要模型切换和忠实结果导出；纯视觉组不能从已渲染图片开始计时。

MO-Parse 接入后的数据表语义化、布局正文还原、页面家具清理、服务正文组装及接口最终渲染不在解析主耗时内。它们可以在服务开发中单独测量，不能与解析耗时混排，不能将服务转换加速或缺失误称为解析方法优劣。

HTTP 传输、接口排队、轮询、下载及文件/数据库纯持久化排除。必要资产裁剪、渲染和编码属于解析处理；输入上传、输出落盘和资产下载属于接口或存储。入口与出口直接设置在计算边界，不能用 HTTP 总时长减常数或估计开销推算。

阶段真实起止点用于解释费用，重叠区间不能相加冒充完整 walltime。共同前处理与缓存策略对八组一致，不能免费复用另一组的页面图。HTTP 契约和服务保存/下载的一致性属于独立工程验收，不构成本轮处理性能结果。

当前服务、适配器与 native worker 的 `duration_ms` 口径不同，有的含传输、等待与写盘，有的缺少前置 PDF 读取；均不能直接复制为正式主耗时。实际入口与止点仍须准备并核对，不能通过减去局部阶段或求和重叠区间修补。源码范围见[调用与计时边界](../docs/engineering/architecture.md#现有调用与计时字段)。

初始化、模型加载和预热单列。性能决策至少使用 3 次同条件代表性工作负载，报告每轮、中位数与波动；完整文档内容回归可一次运行并注明 n=1。逐件 walltime、页数和整组处理时间分别保留，平均每页处理时间不能称为逐页延迟。

保存代码、镜像、权重与配置指纹，以及 CPU、内存、GPU、功率、并发、缓存、CUDA Graphs 和超时条件。失败、超时及清理使用同一处理侧时钟单列，缺测保持未测。共同重试和取消规则预先固定，实际额外解析、切换或重算不得省略；不能静默增加第二解析器。

## 待补输入任务

独立图片与截图、Office 原件及固定转换件、视频、手写文档、完整公式转录、多语言大样本、新的未见模板家族和额外公开文档不因语料生成转到外部项目而自动纳入。恢复或新增须用户明确要求，并交接完整输入与来源金标；现有嵌图和印章不等于这些任务已具备覆盖。
