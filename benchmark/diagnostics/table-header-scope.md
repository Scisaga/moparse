# 表格评分中的内部表头作用范围

标签两端按实际字词与数值边界匹配，不能从`2025/26`、`2025-2026`或`2025.0`截取`2025`；完整行列路径在原生表体内联合定位，重复叶标题由已有父跨度和明确关联消歧；显式路径支持相邻文字分段变化。正确数值不参与定位。范围内单位、期间和附注从实际输出证据读取，缺失、冲突和不明确的要求均使该目标判incorrect，保留全部分母。软件实现在[information.py](../../moparse_eval/information.py)及[评分器](../../moparse_eval/scoring.py)，主评价定义只维护在[评测标准](../evaluation-tasks.md#4-指标与匹配)。

[人工构造的信息用例](../../tests/unit/test_moparse_eval_information.py)覆盖JSON、HTML、Markdown等价信息、多年度重复叶标题、重复行名、完整路径二义性、符号边界、数值排版空白、错单位、缺限定语和重复认领；这些用例不读取任何真实原件或参考。正式重评分范围为既有八组原生产物及P07/P08唯一基线，实际执行证据不自动提供新协议的质量结论。

2026-10-28通过人工编写的HTML、JSON及partial残余结构复现并修复。本文件仅记录评分软件缺陷，不保存失效的真实页面分数；当前结果由[评测索引](../reports/README.md)维护。

## 缺陷

共享网格字段读取原先只检查行列交叉位置，可能把同一body里另一段的列头借给当前记录。合成HTML先显示2024表头及Revenue/900，后显示2023表头及Cost/200；即使值格明确声明`headers="revenue y24"`，原实现仍可能把Revenue/2023/900判为正确。已经保留的HTML属性没有参与约束，因此这不是管线缺少原生关系。

服务partial读取还把多个明确的source header scope合入一个残余body，丢掉了已有作用范围。只修这一处不能解决普通原生HTML的同型问题。

## 修复

[共享评分器](../../moparse_eval/scoring.py)先尊重真实HTML的headers/id与完整声明链，再使用已有网格。破损、循环、重复身份和非header引用不回退借用无关列头；附加合法单位或轴标题不会仅因未出现在参考路径中被拒绝。多个独立表头组同时关联而无法唯一归属时保持未知，判断不依赖年份文字或参考数值。

存在明确列标题角色时，按目标原生行列位置限定连续表头组；不能借下方或被后续组替代的表头。相邻多层表头、明确跨度与显式HTML链分别保留，跨作用范围的跨度保持未判。没有明确角色的普通网格及JSON完整显式路径继续使用既定口径，不新增按内容猜测表头的规则。

[服务读取器](../../moparse_eval/service_observation.py)按明确且实际可见的source header scope分隔partial观察，保留真实字符范围。缺失显示标题、重叠或跨界单元格保留文字，关系保持未知；不能用private证据补入未显示的值。精确且唯一显示、完全不与已知scope相交的未分类残余段保留实际网格几何，不新增语义角色。读取只接受当前冻结执行的观察格式，撤回阶段的旧格式不提供兼容入口。

## 验证与成绩处理

[共享作用域测试](../../tests/unit/test_moparse_eval_information.py)和[partial读取测试](../../tests/unit/test_service_partial_scope_readback.py)仅使用人工结构，覆盖正确及错误期间、明确ID关联、完整多层链、附加合法上下文、损坏引用、重复身份、内部同名表头、源跨度及未显示private内容。它们不读取原件或参考。

修复后统一重评全部八组既有原生产物及当前实际正文，推理输出、执行时间、原件和冻结参考不变。错误成绩、图表及其评分快照直接删除，不作为历史质量基线。当前expected-only评分不读取原PDF、页图、OCR或历史视觉裁定。

## 完整文字与业务表达读回

普通段落仅含冒号、分号或以冒号结束时仍按完整正文比较；明确业务断言可以额外展开字段，剩余字面范围继续保留。带符号标量不拆成标签，括号内单位及附注不误作新的字段名。一个单元格中的多个明确事实各自展开，同时保留原网格，避免新读回视图遮蔽原值或冲突陈述。

候选标题、普通文字及列表中的完整断言遵守同一读回规则。普通文字按自身已打印标题与顺序定位，重复签名、正文中提到的标题和实际标题分别保留；数字相邻边界与否定词不能被子串匹配藏掉。外部caption、标签内单位与局部限定使用相同政策，expected明确的局部单位不能被常识适用性过滤。

重复标题采用自身已打印父范围和局部出现位置，中文标题的分块、枚举空白及引号字形只用于定位，不改写字符成绩。附件引用与后续实际表格标题分别定位。完整长名称先取得自身范围，避免短前缀占用；近似段落中的插入说明仍独立比较。单列属性只按实际列标题读取，普通评级表中的同名记录不能制造额外的纵向属性断言。

同名的普通文字标题和Markdown标题共同参与定位，不能用后来带标记的标题遮蔽前面的实际父范围。命名父记录中的主体和字段范围同时约束嵌套正文，共享列名可在其实际行关系支持下服务多条记录；不能把语义列表重复列名机械解释为必须重复印刷相同表头。候选只从自身打印的列表父路径、单元格和表头建立读回证据，不借隐藏IR或参考补答案。

[完整链独立反例](../../tests/unit/test_expected_contract.py)从Docling、Paddle、GLM、DocVortex和视觉SDK原生形状以及HTML、GFM、列表开始，覆盖多事实、正反号、否定、单位、附注、年度、分组、格式变化与冲突。同一候选改管线或样本标签不能改变判定，内部元数据变化不能改变final.md成绩。这些是评分软件验证，不是语料认证或输出质量成绩。
