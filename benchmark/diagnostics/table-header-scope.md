# 表格评分中的内部表头作用范围

2026-10-29新增信息目标读取修复：标签两端按实际字词与数值边界匹配，不能从`2025/26`、`2025-2026`或`2025.0`截取`2025`；完整行列路径在原生表体内联合定位，重复叶标题由已有父跨度和明确关联消歧；显式路径支持相邻文字分段变化；找不到显式路径不再报告“已定位位置缺值”。每个输出值格的重复认领保持未判，正确数值不参与定位。范围内单位、期间和附注从实际输出证据读取，分别记录正确、错误和未知。软件实现在[information.py](../../moparse_eval/information.py)及[评分器](../../moparse_eval/scoring.py)，主评价定义只维护在[评测标准](../evaluation-tasks.md#4-指标与匹配)。

[人工构造的信息用例](../../tests/unit/test_moparse_eval_information.py)覆盖JSON、HTML、Markdown等价信息、多年度重复叶标题、重复行名、完整路径二义性、符号边界、数值排版空白、错单位、缺限定语和重复认领；这些用例不读取任何真实原件或参考。本轮正式重评分范围为既有八组原生产物；服务运行08的执行证据不因此获得新协议的质量结论。

2026-10-28通过人工编写的HTML、JSON及partial残余结构复现并修复。本文件仅记录评分软件缺陷，不保存失效的真实页面分数；当前结果由[评测索引](../reports/README.md)维护。

## 缺陷

共享网格字段读取原先只检查行列交叉位置，可能把同一body里另一段的列头借给当前记录。合成HTML先显示2024表头及Revenue/900，后显示2023表头及Cost/200；即使值格明确声明`headers="revenue y24"`，原实现仍可能把Revenue/2023/900判为正确。已经保留的HTML属性没有参与约束，因此这不是管线缺少原生关系。

服务partial读取还把多个明确的source header scope合入一个残余body，丢掉了已有作用范围。只修这一处不能解决普通原生HTML的同型问题。

## 修复

[共享评分器](../../moparse_eval/scoring.py)先尊重真实HTML的headers/id与完整声明链，再使用已有网格。破损、循环、重复身份和非header引用不回退借用无关列头；附加合法单位或轴标题不会仅因未出现在参考路径中被拒绝。多个独立表头组同时关联而无法唯一归属时保持未知，判断不依赖年份文字或参考数值。

存在明确列标题角色时，按目标原生行列位置限定连续表头组；不能借下方或被后续组替代的表头。相邻多层表头、明确跨度与显式HTML链分别保留，跨作用范围的跨度保持未判。没有明确角色的普通网格及JSON完整显式路径继续使用既定口径，不新增按内容猜测表头的规则。

[服务读取器](../../moparse_eval/service_observation.py)按明确且实际可见的source header scope分隔partial观察，保留真实字符范围。缺失显示标题、重叠或跨界单元格保留文字，关系保持未知；不能用private证据补入未显示的值。精确且唯一显示、完全不与已知scope相交的未分类残余段保留实际网格几何，不新增语义角色。读取只接受当前冻结执行的观察格式，撤回阶段的旧格式不提供兼容入口。

## 验证与成绩处理

[共享作用域测试](../../tests/unit/test_moparse_eval_header_scopes.py)和[partial读取测试](../../tests/unit/test_service_partial_scope_readback.py)仅使用人工结构，覆盖正确及错误期间、明确ID关联、完整多层链、附加合法上下文、损坏引用、重复身份、内部同名表头、源跨度及未显示private内容。它们不读取原件或参考。

修复后统一重评全部八组既有原生产物及当前服务候选，推理输出、执行时间、原件和冻结参考不变。错误成绩、图表及其评分快照被替换，不作为历史质量基线；实际执行与原页目视记录继续保留各自身份及范围。
