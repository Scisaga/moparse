# MO-Parse 服务后处理保全修复

2026-10-28针对P07同族服务路径检查原生结果读取、正文导出、结构化交接及表格语义渲染。本记录只描述可用受控结构复现的软件缺陷与修复；不读取参考答案，不提供真实页面分数、质量增幅或新的管线排名。

| 缺陷 | 修复后的行为 | 验证入口 |
| --- | --- | --- |
| 一处畸形区域使已成功的邻居无法交回 | worker保留原生块并记录局部导出失败，MinerU与GLM客户端隔离已收到的局部格式错误，保留有效邻居、候选和原页保全入口；资源、截止时间及取消异常继续传播 | [worker导出故障注入](../../tests/unit/test_native_worker_export.py)、[MinerU客户端](../../app/parsers/mineru_native_remote.py)、[GLM客户端](../../app/parsers/glm_sdk_remote.py) |
| 多张HTML表可能被拼为一个网格，上下标可能与数字连写 | 多根或嵌套表不作为单个已确认网格；明确的sup/sub边界保留，`150.1<sup>4</sup>`不变成`150.14` | [HTML读取与区域隔离](../../app/parsers/glm_sdk_remote.py) |
| `x < y 且 z > w`被当作标签删除，代码中的标记被清理 | 仅处理实际HTML语法，先保护Markdown代码块及行内代码；显式上下标保留文字化边界 | [正文导出回归](../../tests/unit/test_export_fidelity_repairs.py) |
| 竖线正文被当作表格从结构化blocks删除 | 只排除已有表对象唯一拥有的显示片段；没有表格归属的竖线正文继续保留 | [整链路合成回归](../../tests/unit/test_postprocessing_preservation.py) |
| 已绑定的单位、期间、附注引用未被渲染或校验 | 完整校验明确的CellRef，按字段输出限定语并保留来源；已显示的同一单元格不重复 | [表格语义回归](../../tests/unit/test_table_semantics.py) |
| 空字符串被自动描述为“原表留空” | 空字面量保持为空并保留标签；只有明确的source_blank状态生成该说明，不因单个空值丢弃有效邻居 | [表格语义回归](../../tests/unit/test_table_semantics.py) |

这些修复不新建表头、单位、期间或附注绑定，不改变网格用途判断、跨页范围和模型解码。当前GFM会转义保留的上下标标签；边界保全不等于完成脚注语义关联。未获得的原生信息仍然未知，完整服务契约的剩余差距见[输出规范](../../docs/specs/moparse-output-spec.md#9-当前实现差距与迁移)。

另已为固定版vLLM 0.19.1补齐生产Compose的GLM native rotary选项；部署步骤、实际检查到的运行身份及未生效状态仅在[运行手册](../../docs/operations/runtime-recipes.md#glm-mrope-运行配置)维护。这里的代码与配置修改未执行推理、重建或重启服务，不能据合成测试宣称线上准确率已经提高。

本轮原生管线比较保持冻结产物和既有计时；MO-Parse服务转换成本与质量必须另行验证，不用服务修复重写[八管线报告](../reports/20261026-lite-v3/report.md)的分数。

后处理执行与最终读取分别通过定向合成回归、Ruff、mypy及非语料文档检查；实际范围、冻结身份及验证记录由[评测索引](../reports/README.md)链接到当前服务运行。跨模块回归还确认局部失败的原页保全入口不会再次清空有效正文。这些受控检查不加载模型或访问真实语料与参考。

后续[最终读取回归](service-readback.md)补齐真实分页符、行内单元格及一致标签定位；[入口修复](service-entrypoints.md)处理原生正文与局部关系，[共享评分修复](table-header-scope.md)约束内部表头作用范围。质量和开销只由当前正式报告呈现，执行、评分及报告生成身份分别保留，线上服务保持原状态。

## 2026-10-29：P07和P08的连续正文适配

新增[最终正文阶段](../../app/services/final_content_service.py)，按原生声明连接相邻正文，将生产者页标记、明确页码及内部处理注释移出正文，保存逐字符编辑记录。PDF图片使用正文引用，资产ID和处理状态保留在内部结构；图片语义不在本次范围。P08读取视觉SDK原生块，接受合法的`content=None`容器，不使用PDF文字层补答案。

| 缺陷 | 修复与边界 | 受控验证 |
| --- | --- | --- |
| 复合标题被读取器整个当成单位，例如把“资产（万元）”作为unit值 | 与行列标题同源的限定信息继续由实际标题提供，只有独立限定字段才填显式unit或period；不能用正确标题挽救另一个明确错误单位 | [最终结果读取](../../tests/unit/test_moparse_eval_service_observation.py) |
| 内部期间表头未识别月份范围，后续收入继承了前段余额日期 | 源页表头识别接受明确的年内月份范围，建立独立作用域；不接受带预测叙述的整句话 | [表格入口](../../tests/unit/test_pdf_table_entrypoints.py) |
| 已确认数据表中的项目和关联方分离，记录没有完整主体上下文 | 具有唯一明确主体列的既有数据作用域，将项目与主体列共同保留为行身份；多个主体候选和正文网格不因此获得数据表身份 | [表格入口](../../tests/unit/test_pdf_table_entrypoints.py) |
| 原生bold span在中文标点旁导出为不能闭合的星号 | 仅在完整typed文本与既有渲染完全对应时，将明确加粗span表示为strong标签；不猜测字面Markdown、公式或未知样式 | [最终正文](../../tests/unit/test_final_content_service.py) |
| 宽标题的框与窄正文列相交，被当成该列漏掉的段落补入 | 补充正文要求可比的水平范围，跨栏块不能借任一窄列作插入锚点；保留原生正文和未知范围 | [原生正文](../../tests/unit/test_native_text_service.py) |
| 上游已隔离的非对象原生块在最终正文阶段再次触发异常 | 私有读取视图将非对象块作为续接阻隔，保留原始回包与有效邻居，不使整篇发布失败 | [最终正文](../../tests/unit/test_final_content_service.py) |

这些是实现与读取缺陷的诊断，不构成真实语料的新验收。修复前的本轮临时评分和派生图表不进入当前报告；两组使用修复后同一冻结软件重新处理，当前候选、评分和逐项损失由[评测索引](../reports/README.md)维护。
