# 文本附注转写的数学标签反例

受控合成表格的列标题为Item和2034，行标签为`\( x^2 \)`，值为17，另有编号2的说明。只凭同号附注会把变量的平方改成附注标签；因此“存在同号说明”不足以允许改写数学标签。这是软件反例，不是语料复核或解析质量结果。

本轮收紧为：只有已绑定附注支持的完整英文多词文本标签才采用附注正文转写。单字母变量、平方量纲、单独单词、数学运算式和未绑定标记继续按原字面打印，值不经过该转写。正反例保存在`tests/unit/test_native_table_context.py`，最终正文读取与原有GFM、实际HTML的范围验证保存在`tests/unit/test_moparse_eval_service_observation.py`。
