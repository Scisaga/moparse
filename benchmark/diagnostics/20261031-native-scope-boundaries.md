# 原生结构与局部限定的软件诊断

单位caption改为逐值限定后，原生分类器未识别季度表头时，空的原生范围提案曾覆盖已有PDF来源范围的上下文归属。当前caption使用已声明且完整的实际表头范围；原生分类器提案为空不清除已有范围。仅带百分号的列标题也明确阻断金额单位继承，受控季度表和百分比列覆盖此路径。

旧正文的保留表格可能没有后来增加的空context_rows声明。读取器此前按当前生成的完整注释定位，导致这些原样存在的HTML被漏读。当前只允许省略确实为空的该字段，其余来源行、表头、跨度与显示坐标仍须符合已保存候选声明；非空上下文不能省略，错误期间和改动坐标不获得关系加分。此修复只读取已打印的候选，不修改旧正文或冻结参考。

本文件只记录代码缺陷与受控软件反例，不是原件、参考内容或解析质量验收。实际候选、开发暴露与人工来源判断由[当前评测索引](../reports/README.md)维护，不从这些软件检查推定语料通过。

矢量表格来源读取曾在确认外框闭合之前比较行列数，不完整局部格线由此可能被误记为完整来源分区冲突。实现现先确认外框，并把同样行数、仅一列物理格网的情况记为缺少内部列划分证据，不用物理格线的粒度否定已读出的多列业务字段。受控新建PDF覆盖闭合多列尺寸冲突仍阻断、外框不完整及单列粒度不足允许已有原生结构入口；逐格文字、跨度及归属冲突保护未放宽，历史证据不重写。

局部单位曾被完整嵌入期间列名，或把单位caption作为业务标题重复到所有记录。当前使用已有行单位、印刷百分号及明确每股金额限制单位继承；同期间独立币种列仍保留身份，普通货币符号不能取消百万量纲。单位caption的精确原文范围进入已有TextRef，业务标题中的货币字样不被改成单位。

原生制作footer曾只检查整块起始字段，多个制作字段同处一块时会漏清理。当前识别多字段束，仅容纳同一束已有键词和明确翻译布尔标记组成的原生span碎片；混入其他业务文字或只有单一DRAFT限定的页脚保留。明确货币金额与下一相邻同页文本开头数量单位的字面断裂可续接；无货币限定、独立新句、代码、公式、跨页及跨区域反例不续接。

无名数值行保留已有分组标题，仍不声明汇总角色、不补Total或Subtotal、不计算合计；没有对应分组时不借其他表或此前已关闭范围的标题。已印刷汇总词仅横跨序号与明确名称列的记录则可关联剩余字段，不把合计当作人员名称；跨计量列及未命名反例继续保留。未支持的连续汇总正文继续记录为未通过，而不是用内部引用或网格保全宣称完整转换。
