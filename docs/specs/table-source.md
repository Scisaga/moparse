# 表格来源与证据约定

本文规定 MO-Parse 转换时如何保全和使用表格来源证据。先按[逐管线输出与适配说明](../pipelines/README.md)确认本组真实结构和字段，再解释来源与关系；处理流程是管线原始结果 → 本组适配 → MO-Parse 内容处理与组装 → 目标文档；服务按后端已有的 Markdown、HTML、XML、JSON 或 SDK 结构接入，不要求先生成 GFM，也不要求候选解析管线实现本项目的内部表示。

表格来源和语义转换只维护一套当前定义，直接随代码修改，不分内部协议版本，不保留旧格式解码分支或自动迁移入口。历史原件、实验结果、镜像名称与校验值保持原样，供审计追溯。本来源约定不定义通用文档结构、资产索引或 ZIP 格式，交付范围由输出契约维护。

[输出规范](moparse-output-spec.md)统一规定数据表表达、布局正文、图片保全和输出包；本文件只定义来源证据及其使用。GFM 仅是具体显示方式，其字段、语法表头与行映射见[表格显示映射](../engineering/architecture.md#表格显示映射)。

## 先确认网格用途

来源中的网格可能承载数据表，也可能只用于排版段落、栏目、标题和插图。闭合格线、矩形单元格、对齐、文字逐格匹配、后端 `table` 标签或 HTML 标签都只是观测，不能单独证明数据关系。建立来源网格与认定语义数据表是两件事。

分别记录数据表、网格排版、混合区域及用途未知的判断与来源依据。数据表须有来源支持的字段与值、记录或行列数据关系；网格排版保留正文与图片，按可确认的阅读顺序还原，不把相邻单元格自动绑定成字段与值。混合网格按区域处理，未知类别不进入确定的表格关系转换，也不能默认为普通正文并丢掉可能的关系。

保留原始网格、文字、区域和原图以便复核；显示代码仍可展示网格，但显示表头、行号及表格角色规则不能用于布局正文。独立标注应包含纯排版网格与混合区域，分别核对内容、顺序、分类错误和虚构关系。

## 来源文字、网格与状态

2026-10-30工作区新增原生单元格入口：已有单元格文字、原行列、跨度及来源身份可以独立证明结构可读；完整PDF格网是补充证据。用途与关系仍须由明确字段、标量记录和实际表头范围支持，原生table标签与跨度本身不构成分类。已记录的来源文字、跨度或归属冲突继续阻断相关转换，不能以切换入口掩盖。原生未保存的缩进、粗体层级保持未知。

在已经确认的计量表范围内，原生整行合并的短分组名与空值分组行采用同一有界分组读取；“加”“减”等算术提示不作为主体父分组或计算事实。原生证据没有给出其结束范围时，保留该段至下一明确表头的原表内容，继续处理范围外已确认记录。同一期间下用于区分列的币种和单位表头必须保留列身份；比例值的计量单位与该列的原文范围标签分别记录，不能把金额单位赋给比例。完整来源路径在渲染后仍须可审计。

保留物理表身份、原文、原始行列、单元格、rowspan、colspan、单位和标题原文及出处。来源网格使用源格锚点和跨度占位，不因显示需要插入来源行、移动源格或改写文字。原格和语义引用的行列从 0 起算；物理页从 1 起算，逻辑合表的行号不能替代物理来源位置。

在已确认的数据表内，未知角色的首行仍是数据。表头检测不能一直延伸到首次出现纯数字的行，把此前的文字记录或带文字说明的金额吸收为表头。无法确认文字记录的字段结构时保留该表，不将后续数值绑到这些记录的文字和值上。真实空白、跨度占位、零、破折号和识别缺失分别保留，不能互相替换。`unknown` 表示证据不足；`null` 或 `[]` 不能改成 `[0]` 来假设首行表头，没有执行布局检测也不能解释为原件无表格。

结构可用只说明当前网格和跨度证据能够使用，不证明该区域是数据表，也不证明正文完整、表头语义完整或全部文字正确。用途未确认、未检测、未识别、方法未支持、来源冲突、原件歧义和处理失败分别记录；源冲突保全、失败页图片和 `partial` 等状态不能因网格重建成功而变成完整成功。

## 表头与限定语作用域

完整表头需有来源文字、单元格、跨度和作用域证据。原生 HTML 的 `<th>` 是角色观测；部分 `<th>`、孤立首行提示、粗体、居中、着色、相同文字或相近布局不能单独证明完整表头。全部 `<td>` 只说明该解析输出未给出表头角色，不能据此断言模型本身的能力。

表头可以位于表格内部，单位、期间和附注也可以在内部改变。按来源行保留每个作用域的表头、正文范围、完整性和证据，不能将第一组标题套用整张表。局部角色观测与完整作用域分别保存；一个重建网格或匹配字形不自动证明这些角色。

当前直接PDF结构绑定有两条入口：完整矢量格线与字形、跨度对应，或后端明确单元格区域构成完整分区且能与源字形逐格对应。ROI按实际线段裁取，合法来源不再仅限MinerU；结构绑定与表头、字段关系仍分别判断。多层表头、数字期间、行分组和短字段分别需要完整来源范围及独立关联证据，不能用结构成功、样式或相同文字直接证明数据表用途。实际方法及限制见[架构说明](../engineering/architecture.md#当前-pdf-路由与来源能力)及[实现](../../app/services/pdf_table_evidence_service.py)，不启动独立的第二解析器复核MinerU。

矢量路径先确认检测分区的完整外框，再比较其行列数与原生结构。外框未闭合的局部格线只表示此来源方法未能建立完整分区；行数相同但仅有一列物理格网时，未观测到内部列划分，不能据此否定原生已声明的多列业务字段，记录来源方法粒度不足并继续独立的原生用途与关系判断。其他闭合多列分区的尺寸冲突、逐格文字或跨度冲突与字形归属歧义继续阻断相应转换；历史诊断字节保留，不用新判断改写旧证据。

## 跨页来源与继承

先保留完整物理表，再核对完整表头、跨度、单位、标题、列边界、页面家具及非表格上下文，确认关系后建立逻辑关联。相似首行、同列数、视觉邻近或原生续表提示单独都不能授权删表头、继承或合表。新增单位或标题开启新作用域；关系未知时保留分表与未知状态。

同列网格合表时，保留各页的原始来源行及已确认重复表头的删除映射。当前 CPU 补充角色的连续表另需已验证的续表边；有序数据路径还核对来源连续序号与原生续表提示。上页紧邻的原文单位可以限定续表范围，不能猜补下页标题。

不同列数的物理网格可能共享表头作用域。例如上表的列组为 `[0]`、`[1,2]`、`[3,4]`，下表为三列；此时保留两个网格，通过 `inherited_header_scope` 引用上表，不能直接合并五列与三列，也不能将上表标题复制成下表的来源行。

继承记录中的 `source_table_id`、`source_page`、`header_rows` 和 `source_column_groups` 指向前表，`body_rows` 与 `body_columns` 指向当前表；前表可用 `continued_bodies` 保存反向引用。完整继承关系与当前物理表存在表头分别判断，当前表的表头仍可未知。继承必须有原生续表提示、完整来源格线与字形绑定、列组边界相符、后续样式相容以及无插入的非表格上下文等独立证据。

## 关系转换与审计

限定来源允许`CellRef`与`TextRef`。后者保留本表身份、物理页、原生块身份、原文字符范围、原文、限定类型及适用行列；单位、期间与附注可指向明确表前正文或本表原生caption、footnote，不再要求这些内容必须占据单元格。上下文采用已声明且完整的实际表头作用域；原生分类器未提供范围不能清除已有来源范围的单位归属。标题与单位不能跨另一张表或新范围继承；上一表本体及包含表格结构标记的原生片段不能作为下一表的单位或标题，明确单位caption的币种字段保持原字面范围。金额、占比与同比列分别处理。实际正文必须显示适用的范围与限定，内部引用不代替正文表达。数据关系逐行建立，局部不支持区域原样保留；共享跨度不能跨越未解决区域强行拆分。

表达数值前，关联完整行列标题路径、单位、期间、适用范围、附注和源格。明确金额或余额字段的空字面槽位也保留其已有单位范围，但不填零、不声明来源空白状态，不把单位套给空序号、备注或比例字段。标签和值从来源读取，不按指标名、版式模板或业务常识补造限定语。逐格比较只采用明确的 ASCII 全半角与排版空白政策，不使用 NFKC、同义词、大小写或数值改写；原文和严格字符诊断保留，比较等价不能授权合表或修复字符。

原始解析、来源结构、语义关系和最终正文分别保留身份与校验依据。当前[表格关系与来源引用](api.md#表格关系与来源引用)记录有限转换及未解决范围；显示行号不能用于语义段落的源格引用。最终转换仍须核对内容、关系、覆盖和状态，处理完成与完整语义转换完成分别报告。

转换状态分为converted、partial和retained。partial只输出完整支持的记录行及其关系，其他行按原顺序保留为剩余网格；数据值不在完整原表和语义条目中双写。跨越已解决与未解决行的合并格作为一个来源组件保留，不能拆分共享值。`retained_cells`、`retained_rows`与`row_issues`登记未解决来源，剩余显示片段明确原行到显示行的映射；全空语法表头不冒充来源表头。

剩余片段的真实行跨度与列跨度须进入实际显示；可用HTML表达时沿用来源跨度，不以内部映射代替正文中的共享标题范围。含嵌入图片等尚不支持的显示仍保留原内容并报告限制。文本标签中的数学包装只有在本表已绑定的附注明确解释对应标记时，才可转写为标签与可见附注标记；当前实现仅处理完整的英文多词文本标签，单独变量、单词、量纲、数据值及无明确附注的上标继续保留字面表达。格式转写不补充新的业务关系，不宣称通用数学解释能力。

完整单位caption保存为具有精确原文字符范围的单位引用，不作为套到所有行的业务标题；已有行单位、比例列、印刷百分号及明确每股货币金额分别限制其继承。具有明确期间的列路径中，嵌入列名末尾的金额单位在本行已印刷独立单位、数值已带百分号或明确每股字段已带货币金额时让位于该局部表达；保留列名的业务部分、期间与原始审计路径。不按指标常识猜单位，不因数值带货币符号就取消百万量纲；同期间的独立币种列身份仍保留。无行名数值行的剩余片段可重复其已有明确空值分组标题，但不能借此补行名、重算合计或认定汇总角色；已转换数据值不重复写入片段。

已有明确序号与名称字段的记录表内，实际印刷的合计或小计文字仅横跨这两个标识列时，可作为汇总标签关联其余明确字段和值，不把合计标签当作人员、股东或认购方名称。名称字段照原文识别股东名称、认购方等明确身份；跨到计量列、未印刷汇总词或未知字段结构的区域继续保留，不推算总数。

接入端消费服务结果，不能自行删除未确认重复头、拼表、改值或猜测财务期间。历史记录只用于追溯，不作为维护多版本内部协议的要求，也不构成八组解析比较的原始能力成绩。
