# ADR-0001：面向信息抽取的最终语义 Markdown

状态：2026-10-19 采纳目标契约，2026-10-20 统一表格来源与语义表示的当前定义。全部表格、PDF 流程图与组织结构图必须语义化，最终正文去掉页码、页眉页脚。当前表格语义实现仅为部分实现，尚未满足完整目标；去版本化不扩大转换能力，也不执行推理或部署。

## 背景与变更

此前将移除公开 Semantic XML、坐标 JSON 与取消表格语义转换捆绑，形成以 GFM 为最终正文的边界。之后恢复了部分表格的语义表达，但仍把原表保留作为最终兜底，未覆盖流程、组织关系和页面家具清理。

用户现已明确最终输出用于下游信息抽取：所有表格都转换为语义描述，流程图与组织结构图也转换，建议使用多层列表；页码、页眉页脚去掉。前序解析允许 Markdown、XML 区域定义或其他中间表示，由最终转换步骤统一输出。本文撤销保留比较矩阵或未转换原表作为最终合格正文的旧决定。

## 决策

唯一公开文档仍为 `result.md`、`text/markdown`。最终表达采用业务标题、段落与多层列表，规范以[最终语义输出契约](../output-contract.md)为准。任务 JSON 和资产索引继续作为控制数据，不增加第二份公开文档结果。该决定约束 MO-Parse 转换后的服务结果，不要求底层解析器或研究侧导出直接满足；候选管线可以保留表格、源图及页面家具。

来源解析、语义关系、页面家具识别与最终转换分层。中间 Markdown、HTML、XML 区域定义、物理表和原图按需保存，不能直接作为最终抽取正文。原始文字与数值从来源读取，关系和限定语均需来源支持。

所有表格按字段、记录、完整行列标题、单位、期间、附注及作用域表达，包括比较矩阵和混合、跨页结构。流程图表达节点、连线方向、条件、分支、汇合、回路和分组；组织图表达层级、分组与来源明确的交叉关系。列表不能改变原图拓扑，未知连线不能推断为控制或隶属。

最终转换删除物理页码、重复页眉页脚、分页及调试信息，保护业务标题、附注、签章和日期。详细物理页、坐标、网格和图形定位留在证据层，短引用用于按需追溯，不要求下游重新理解页面版式。

## 未完成与来源保全

保留原表或原图是内部证据保全，不算最终语义转换完成。程序不支持、识别缺失、关系冲突和原件不可辨分别记录；部分结果可列出已确认内容和未解决范围，但不得宣称满足最终契约。删除失败区域或仅把表格语法改成列表也不算正确转换。

[表格来源与证据约定](../table-source.md)和[表格关系与来源引用](../api.md#表格关系与来源引用)分别规定来源保全和当前转换记录，只维护一套当前定义，不划分内部协议版本或保留旧格式分支。GFM 只用于具体显示，不作为统一中间模型或候选必经出口。历史证据保留原字节与 SHA，不自动迁移；公开路由、文件名、媒体类型和任务身份保持现状。

MO-Parse 负责来源已有的语义表达，实体消歧、指标归一、控制关系推断、业务事件抽取、事实去重和修订继续属于下游。允许内部 XML 不表示恢复公开 Semantic XML 或公开详细坐标 JSON。

## 解析研究与服务实施

解析预期结果与语料的生成已在其他项目开展；解析研究接收外部交接的原件、类别与独立内容和结构标注，固定八组身份、忠实导出、资源与计时，再比较原始解析质量与成本。有实际类别差异后才研究方法选择或路由；不把共同语义接口、转换组件或本契约达标作为对照前提。

MO-Parse 服务按交接的全部表格、流程图、组织图与页面家具清单核对覆盖，开发接入、关系转换、清理和最终正文组装。功能可用正确结构单独测试，再用真实解析结果做服务内容与接口验收；服务转换和必要的原件补充单独记录费用，不能计作候选本身能力。两项工作可并行，方法结论用于后续接入，不要求管线研究先实现服务最终格式。

研究问题与方法见[研究框架](../research-framework.md)，工程交接见[技术路线](../technical-route.md)，解析任务与评分见[评测任务](../../benchmark/evaluation-tasks.md)，八组身份见[管线计划](../../benchmark/pipelines-to-test.md)。不因目标要求直接增加第二模型或 Docling 复核，也不把服务最终格式变化称为解析方法优劣。

已有表格语义实现的[历史记录](../research-framework.md#101-2026-10-19-表格语义有界实验与实现)只说明当时覆盖的表格转换及接口结果，不证明全部表格、图形或清理合格。完整服务目标仍需实现、真实内容验收与按授权部署；本轮文档修订不启动执行。实现缺口见[最终契约](../output-contract.md#9-当前实现差距与迁移)。
