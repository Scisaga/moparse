# MO-Parse 数据集

已交付[Lite](moparse-dataset-v1-lite/README.md)和[Full](moparse-dataset-v1-full/README.md)两个独立可迁移目录。Lite以作者实际视觉交接冻结800个输入页；Full按人工资料清单保存全部现有参考及完整原件，历史说明为113份、7,070页，不作本轮全文验收声明。

标准唯一维护于benchmark/evaluation-tasks.md。authoring保存人工选择及交接，不能作为机械检查入口；datasets及含语料的benchmark/reports永久排除通用仓库检查。

preflight和deadline-probes目录仅服务工程预检及共同超时标定，复用Lite原8页的已确认来源，不是第三个正式评测集，也不增加800页预算。
