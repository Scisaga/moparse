## 图像索引与自动定位边界

C 手写的 kind=image 目标保存物理页与参考引用，没有 literal，也未标可用于跨候选自动比较的像素指纹或图片语义。早期样本如 byd-bilingual-front-p001-012 的 cover-image、product-chart 通过 reference 指向 expected.md 的图像行；后期样本如 byd-outlook-finance-p037-044 和 sinopec-finance-governance-p025-036 直接 reference.path 指向 references/.../assets/*.png。选入的图像参考文件均曾单独展示并直接对照原页，范围仅为保全；未选图像未因此获确认。

参考文件名不是候选必须复用的身份。候选图片命名或目录不同，不能仅以不同名、参考路径不存在于候选、无 literal 或文字定位失败判为图片缺失。当前索引足以说明人工保全目标和参考位置；没有独立视觉候选证据的图像保全得分应保持待核实或不可自动判定。原件已有题注、标题或所选正文另外作为 kind=text 目标，不能把参考图像名称当作这些文字的替身。
