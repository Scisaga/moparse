# moparse-dataset-v1-full

本包按人工明确列出的现有expected资料清单，保存全部对应完整原件、现有参考与资产的独立副本。既有作者说明记载113份、7,070页；这不是本轮机械计数或新的全文视觉验收。

inputs包含完整原件，references保留每份现有expected.md、manifest、图片和历史状态；manifest.json是包内运行路径入口。原参考manifest中的工作区路径属于历史导航。包内数据不依赖原语料目录，也没有通过外部符号链接代替资料。

Full保留historical_reference及既有审核、未知和疑点，不因复制完成升级为本轮Gold。原件和参考未重新生成，旧审核记录不能替代新的原页视觉阅读。本轮优先完成Lite选择范围的评分索引，其余Full评分标注留待后续。

本轮不启动Full推理，moparse_eval run拒绝Full包。之后如开展Full评测，应先按实际原页阅读补齐独立评分范围，再冻结标准与配置。Lite与本包共享来源和开发暴露，不能称为两个独立未见测试集。

数据集和评分标准由MO-Parse仓库benchmark/evaluation-tasks.md维护。provenance保留本次收纳依据及历史说明；包装只执行人工清单，没有机械复核、格式/链接/映射验收或内容正确性判定。

原资料来源与许可沿用现有声明；本地打包不授予新的公开再分发许可。
